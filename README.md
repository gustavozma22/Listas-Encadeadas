# Listas-encadeadas
ESTRUTURAS DINAMICAS E ALOCACAO DE MEMORIA

2.1. Lista Simplesmente Encadeada e Matriz Esparsa
- Arquivo: matriz_esparsa_estacionamento.c
- Descricao: Implementacao de uma matriz 10x10 de estacionamento utilizando uma lista simplesmente encadeada que armazena apenas as posicoes ocupadas (diferentes de zero), economizando memoria.

2.2. Lista Duplamente Encadeada
- Arquivos:
  * historico_navegacao.c (Simulador de historico de navegacao web com ponteiros anterior e proximo, com limpeza de memoria futura ao acessar nova pagina no meio)
  * playlist_musica.c (Gerenciador de playlist musical bidirecional com funcoes de avancar, voltar e remocao especifica de nos)
- Descricao: Uso de ponteiros bidirecionais para navegacao em ambas as direcoes e manipulacao dinamica de nos na memoria heap.

2.3. Deque (Fila Duplamente Encadeada)
- Arquivo: deque_equipamentos.c
- Descricao: Fila duplamente encadeada com controle de inicio e fim, permitindo insercoes, remocoes e consultas eficientes em ambas as extremidades.
